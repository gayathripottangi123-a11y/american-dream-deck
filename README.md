# American Dream Interactive Sales Deck

**Live Demo:** https://american-dream-deck-mu.vercel.app  
**GitHub:** https://github.com/gayathripottangi123-a11y/american-dream-deck

A premium, video-first interactive sales presentation for American Dream retail complex. Built with Next.js 14, TypeScript, and AI-generated visual assets.

---

## 🎯 Project Overview

An interactive digital sales deck showcasing American Dream's 3 million square foot retail and entertainment destination in East Rutherford, New Jersey. Designed for leasing agents, event sponsors, and corporate clients.

---

## ✨ Key Features

### Video Integration
- **Custom Video Player** - Built-from-scratch player with play/pause, mute, fullscreen, and scrubbing controls
- **Scroll-Triggered Playback** - Videos autoplay when scrolled into view using Intersection Observer
- **Lazy Loading** - Optimized with metadata preloading for performance
- **3 High-Quality Videos** - Property overview, mall walkthrough, and attraction showcase

### AI-Generated Imagery
- **5 Photorealistic Images** - Created using Leonardo.ai with custom architectural photography prompts
- **Professional Quality** - Luxury mall interiors, aerial complex views, ski facilities, theme parks
- **Seamless Integration** - Optimized with Next.js Image component

### Interactive Features
- **Filterable Store Grid** - Dynamic filtering by category (luxury, fashion, footwear, tech, beauty)
- **Scroll Navigation** - Fixed navigation menu with active section tracking
- **Responsive Design** - Mobile-optimized layouts with touch-friendly controls
- **Smooth Animations** - Particle effects, mouse parallax, hover states

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, GSAP (particles)
- **Icons:** Lucide React
- **Deployment:** Vercel (auto-deploy from GitHub)
- **AI Tools:** Leonardo.ai for image generation

## 📹 Video Integration Details

### Custom Video Player Features
- Click-to-play/pause
- Volume control with mute toggle
- Fullscreen mode
- Progress bar with click-to-seek
- Scroll-triggered autoplay (50% visibility threshold)
- Loading states with spinner
- Hover-to-show controls

### Technical Implementation
- Built with native HTML5 video API
- Intersection Observer for scroll detection
- React refs for DOM manipulation
- Event listeners for time tracking
- Responsive aspect ratio handling

## 📦 Installation & Setup

```bash
# Clone repository
git clone https://github.com/gayathripottangi123-a11y/american-dream-deck
cd american-dream-deck

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to Vercel
vercel --prod
```
